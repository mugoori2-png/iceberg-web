# Quiet Utility

밝은 종이 바탕과 정렬된 글자로 작은 서비스의 내용을 즉시 전달한다. 무엇을 하는지부터 읽히는 구성이다.

크기 대비가 읽는 순서를 결정한다. 작업 이름, 가격, 범위 순서로 시선이 흐르며 작은 화면에서도 핵심이 남도록 정교하게 간격을 맞춘다.

여백은 장식만큼 중요하다. 모든 요소를 공통된 기준선에 두고 한정된 요소의 비례를 반복해서 다듬어 사람이 꼼꼼하게 조판한 인상을 만든다.
