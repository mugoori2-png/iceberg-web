# 크몽 상품 등록 초안 — 업무 자동화 프로그램

크몽 판매자 센터 → 서비스 등록에 아래 내용을 순서대로 붙여넣으면 됩니다.

---

## 1. 카테고리
IT·프로그래밍 → 업무 자동화 (또는 "프로그램 개발" 계열 — 등록 화면에서 가장 가까운 것 선택)

## 2. 서비스 제목 (후보 — 하나 선택)
1. 매일 반복하는 엑셀·문서 작업, 클릭 한 번으로 만들어드립니다
2. 한글(HWP)·엑셀 반복 업무를 자동화 프로그램으로 만들어드립니다
3. 반나절 걸리던 일을 2분으로 — 업무 자동화 프로그램 제작

## 3. 검색 태그 (쉼표 구분)
업무자동화, 엑셀자동화, 매크로, HWP자동화, 한글문서자동화, 문서자동생성, 반복업무, 파이썬자동화

## 4. 패키지 3단계

| | STANDARD | DELUXE (추천) | PREMIUM |
|---|---|---|---|
| 이름 | 단일 자동화 | 문서 자동 생성 | 업무 전체 자동화 |
| 가격 | 200,000원 | 500,000원 | 1,000,000원 |
| 작업일 | 7일 | 14일 | 21일 |
| 수정 횟수 | 2회 | 3회 | 3회 |
| 내용 | 엑셀 정리·취합 등 반복 작업 1종 자동화, 실행 프로그램 전달, 사용법 안내 | 한글(HWP)·워드 문서 자동 생성기, 서식·규격 맞춤, 대량 생성, 실제 파일 검수, STANDARD 포함 | 여러 단계 업무 파이프라인 구축, AI 결합(분류·요약), 필요시 관리 화면, 운영 정착 지원 |

## 5. 서비스 설명 (상세 내용에 붙여넣기)

**하루 30분짜리 반복 작업도 1년이면 120시간이 넘습니다.**

엑셀 정리, 문서 만들기, 데이터 옮겨 붙이기 —
사람이 안 해도 되는 일은 프로그램에게 맡기세요.

**[ 이런 분께 필요합니다 ]**
- 매주 같은 엑셀 정리를 몇 시간씩 반복하는 분
- 같은 서식의 문서를 수십·수백 장씩 만들고 있는 분
- 여러 파일의 데이터를 손으로 옮기다 실수가 나는 분
- "이거 자동으로 안 되나?" 생각만 하고 있던 분

**[ 실제 운영 중인 자동화 — 판매용 데모가 아닙니다 ]**
- OMR 답안지 195장 스캔 채점: 반나절 → 2분 30초, 실수 0건
- 한글(HWP) 시험지·정답지·해설지 3종 자동 생성: 몇 시간 → 클릭 1번
- 성적 취합·등수·개인 리포트 자동 산출: 매 시험마다 실운영
전부 제가 실무에서 매일 직접 쓰려고 만든 것들입니다.
매일 안 깨지고 돌아가야 하는 기준으로 만듭니다.

**[ 이런 일을 자동으로 만듭니다 ]**
- 엑셀 취합 · 집계 · 서식 정리
- 한글(HWP/HWPX) 문서 자동 생성 ← 전문 분야
- 워드 · PDF 대량 생성
- 스캔 이미지 판독 · 채점
- 파일 이름 · 폴더 자동 정리
- 웹 자료 수집 정리
- AI 결합 자동화 (분류 · 요약)

**[ 진행 과정 ]**
1. 지금 손으로 하시는 작업을 그대로 설명해주세요 (화면 캡처·파일 예시면 충분)
2. 자동화 가능 범위와 방식을 정리해 견적을 안내드립니다
3. 실제 파일로 함께 테스트하며 실무 기준에 맞을 때까지 조정합니다
4. 클릭 한 번으로 실행되게 전달하고 사용법을 안내드립니다

**[ 자주 묻는 질문 ]**
Q. 제 업무도 자동화가 되나요?
→ "이 파일 열어서, 이걸 복사해서, 여기 붙인다" 수준으로 설명해주시면 판단해드립니다.
효율이 안 나오는 일이면 만들지 말자고 솔직하게 말씀드립니다.

Q. 컴퓨터를 잘 몰라도 쓸 수 있나요?
→ 더블클릭 한 번으로 실행되게 만들고, 결과는 익숙한 엑셀·한글로 나옵니다.

Q. 회사 파일 보안이 걱정됩니다.
→ 형식이 같은 샘플 파일로도 제작 가능하고, 전달 자료는 완료 후 요청 시 폐기합니다.

**지금 하시는 작업을 설명만 해주세요.**
자동화 가능 여부와 예상 절감 시간을 먼저 확인해드립니다.

## 6. 요청사항 안내 (구매자에게 받을 정보)
- 지금 손으로 하는 작업 과정 설명 (순서대로, 대략이어도 됩니다)
- 사용하는 파일 예시 또는 화면 캡처 (민감정보는 가려도 됩니다)
- 얼마나 자주, 한 번에 얼마나 걸리는지
